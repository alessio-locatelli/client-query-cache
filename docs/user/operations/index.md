# Operations

Before enabling caching, check the [installation requirements](../getting-started/installation.md) and evaluate your [workload](../benchmarks/index.md).

- [Deployment](deployment.md): client and manager ownership, capacity, connection pools, security, and recovery.
- [Monitoring](monitoring.md): cache counters, bypass reasons, stream health, and OpenTelemetry metrics.
- [API reference](../reference/api.md#configuration): exact configuration values and limits.

For a rollback, follow [Rollback to plain PyMongo](../reference/api.md#rollback-to-plain-pymongo). No stored-data migration is required.
