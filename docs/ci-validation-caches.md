# CI validation caches

GitHub Actions runs the checks in `.github/workflows/`. A cache speeds up a later run when its inputs are compatible; every check still runs. GitHub can decline cache writes from forked pull requests, and a fresh runner still runs every check when no cache is available.

The table names every validation command and Prek hook run by the workflows. “None” means the command has no reusable validation cache of its own. Hook installations share Prek's environment cache even when the hook has no result cache.

| Tool or check                                                 | CI invocation                              | Reusable state                                                            | CI persistence                                   |
| ------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------- | ------------------------------------------------ |
| uv (`sync`, `run`, `build`, `tool install`, isolated install) | Prek, Python, performance guard, benchmark | `~/.cache/uv` package and build cache                                     | `setup-uv` in `setup-toolchain`                  |
| Python managed by uv                                          | Prek, Python, performance guard, benchmark | No validation-result cache                                                | Installed by `setup-uv` each job                 |
| Prek                                                          | Prek                                       | `~/.cache/prek` hook environments                                         | `actions/cache` in `prek.yml`                    |
| `check-yaml`                                                  | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| `check-added-large-files`                                     | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| `check-json`                                                  | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| `check-symlinks`                                              | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| `check-toml`                                                  | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| `destroyed-symlinks`                                          | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| `end-of-file-fixer`                                           | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| `mixed-line-ending`                                           | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| `check-case-conflict`                                         | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| `check-merge-conflict`                                        | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| Ruff check and format                                         | Prek hooks                                 | `.ruff_cache`                                                             | `actions/cache` in `prek.yml`                    |
| Ruff extra rules                                              | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| Vulture                                                       | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |

| Typos                                                         | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| Taplo format and lint                                         | Prek hooks                                 | Prek environment only                                                     | Prek cache                                       |
| Detect Secrets                                                | Prek hook                                  | Prek environment; `.secrets.baseline` is a tracked input                  | Prek cache                                       |
| Lychee                                                        | Prek hook                                  | `.lycheecache`, with 14-day expiry                                        | `actions/cache` in `prek.yml`                    |
| Actionlint                                                    | Prek hook                                  | Prek environment only                                                     | Prek cache                                       |
| Just formatting check                                         | Prek workflow                              | None                                                                      | Not applicable                                   |
| npm (`ci`, `exec`)                                            | Prettier workflow                          | `~/.npm` package archive                                                  | `setup-node` npm cache                           |
| Prettier                                                      | Prettier workflow; skipped in Prek         | `node_modules/.cache/prettier/.prettier-cache`                            | `actions/cache` after `npm ci` in `prettier.yml` |
| Markdownlint CLI2                                             | Prettier workflow                          | None                                                                      | Not applicable; npm installation uses npm cache  |
| OpenSpec validation                                           | Prettier workflow                          | None                                                                      | Not applicable; npm installation uses npm cache  |
| MyPy                                                          | Python package job                         | `.mypy_cache`                                                             | `actions/cache` in `test.yml`                    |
| Slotscheck                                                    | Python package job; skipped in Prek        | None                                                                      | Not applicable; uv installation uses uv cache    |
| Package build and isolated import smoke test                  | Python package job                         | No validation-result cache; uv uses `~/.cache/uv`                         | `setup-uv`                                       |
| Pytest and its plugins                                        | Python integration job                     | `.pytest_cache`                                                           | `actions/cache` in `test.yml`                    |
| Hypothesis                                                    | Pytest property tests                      | `.hypothesis` example database                                            | `actions/cache` in `test.yml`                    |
| Coverage and strict-no-cover                                  | Python integration job                     | None; coverage data is temporary run output                               | Not applicable                                   |
| Testcontainers and Docker                                     | Python tests and benchmarks                | No validation-result cache; Docker downloads the configured MongoDB image | Not applicable                                   |
| Performance guard scope and comparison                        | PR performance guard                       | No validation-result cache; uv uses `~/.cache/uv`                         | `setup-uv`                                       |
| Stream cost benchmark                                         | Manual benchmark workflow                  | No validation-result cache; uv uses `~/.cache/uv`                         | `setup-uv`                                       |

The source of truth for enabled Prek hooks is `.pre-commit-config.yaml`; the workflow skips its `slotscheck` and `prettier` hooks because other jobs run those checks. Benchmark reports and failure logs are uploaded as artifacts for inspection, not restored as validation caches.
