# Telemetry producer audit

The production inventory covers `src/client_query_cache/` and
`native/shared-index/src/`, including callers outside the design's initial table.
The policy is fixed when a core or server is constructed. The rows below classify
the remaining producers and the similarly named operational state.

| Classification               | Files and symbols                                                                                                                                                                    | Reason                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Enabled only                 | `_core/manager.py`: `_statistics`, `_stream_cost`, retention-decline arguments, `_process_evicted`, namespace and close logs                                                         | Disabled cores allocate neither collector. Call sites guard recording, decline tuples and routine log preparation. Admission planning and reclamation still execute.                                                                                                                                                                                                                                        |
| Enabled only                 | `_core/snapshots.py`: `CacheStatistics`; `_core/stream_cost.py`: `StreamCostRegistry`, `StreamCostStatistics`, lag windows and apply readings                                        | Managers construct these mutable collectors only when enabled. Snapshot sorting, percentile calculation and export are explicit diagnostic work.                                                                                                                                                                                                                                                            |
| Enabled only                 | `_core/native.py`: `initialize`; `local_cache.rs`: `Statistics`, `LocalOwner::record_*`, `snapshot`, stream-cost methods                                                             | Native state contains `Option<Statistics>`; disabled setup stores Python `None` instead of a stream registry. Cache operations gate every statistical increment; explicit record methods check the mode before locking or crossing into Python.                                                                                                                                                             |
| Enabled only                 | Both `collection.py` and `cursors.py` modules; `_core/cursor_capture.py`; `_shared/adapters.py`: `_observation`, `_outcome`, `_identity_outcome`, `_local_select`, admission helpers | Recording calls and observation-only reason conversion are guarded. Its byte counters and control synchronization are intrinsic to that tool and are outside ordinary manager execution.                                                                                                                                                                                                                             |

Inventory command:

```sh
rg -n 'record_|counter|statistic|snapshot|telemetry|observation|observe|perf_counter|monotonic|time\(|fetch_add|\+=' src/client_query_cache native/shared-index/src
```

References were followed through aliases, helper calls and Rust state methods.
No ordinary default-mode observation producer remains unclassified. Regression
coverage includes forbidden collector construction, absent diagnostic clocks,
timestamp-free event routing, local diagnostic rejection, full queues, native
ring overflow and recovery generations. The performance comparison is recorded
in `reports/opt-in-telemetry/summary.md`.
