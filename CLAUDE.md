## Docstrings and code comments

Never write docstrings and code comments.

_Note that ignore comments that suppress false-positives (e.g., `# noqa`, `# type: ignore`, `# pragma`) are obviously out of scope of these guidelines._

## PR description and conversation

Each piece of information must exist in exactly one location. Do not restate commit-body rationale in the PR description, do not restate the PR/commits/issue in the chat reply, and do not paraphrase or shorten it as a "summary" elsewhere.
